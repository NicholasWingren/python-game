# Turn-Based Python Game

A two-player turn-based game developed in Python.

This project was originally developed as a high school programming assignment in Spain and later organized and documented for my GitHub portfolio.

## Features

- Two-player turn-based combat
- Multiple weapons with different damage and ammunition
- Armor system
- In-game currency
- Weapon, armor, and ammunition purchases
- Special cards with damage multipliers and extra turns
- Player inventory
- Save and load game functionality using JSON

## Technologies

- Python
- Object-Oriented Programming
- JSON
- File handling

## What I Learned

This project helped me practice:

- Classes and objects
- Game logic
- Loops and conditional statements
- User input handling
- File persistence
- Debugging and problem solving

1. Download both Python files.
2. Make sure Python is installed.
